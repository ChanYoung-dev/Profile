# 자기소개서 — 다우기술 비즈플랫폼팀

## 1. 자기소개

다우오피스에 AI를 안전하게 녹여내는 일에 함께하고 싶어 지원한 김찬영입니다. SK 엠앤서비스에서 약 4년간 MSA 기반 커머스의 주문·결제·배송 도메인을 전담했으며, 객체지향 리팩토링·테스트 코드·RabbitMQ 비동기 처리·분산 트랜잭션 설계로 시스템의 안정성과 확장성을 끌어올려왔습니다.

## 2. 성격 장단점

장점은 시스템을 꾸준하고 꼼꼼하게 개선하려는 자세입니다. 주문 도메인은 작은 오류 하나가 사용자 경험과 서비스 신뢰도에 직결되기 때문에, 고객 문의가 들어왔을 때만 대응하지 않고 평소에도 로그와 시스템 상태를 주기적으로 모니터링하며 문제의 징후를 먼저 발견하려 노력해왔습니다. 또한 발생한 이슈를 단순히 수정하는 데서 끝내지 않고, 근본 원인을 분석하여 구조적으로 개선해 동일한 문제가 재발하지 않도록 만들어왔습니다.

단점은 새 기술을 끈기 있게 적용하려다 검증에 예상보다 오랜 시간이 걸리는 경우가 있다는 점입니다. (기능 안정성 → 테스트 → 신기술) 순으로 우선순위를 두고 작업하며, 장애 방지를 최우선에 두는 방식으로 보완하고 있습니다.

## 3. 지원동기

다우오피스는 수많은 임직원이 매일 사용하는 그룹웨어로, 제가 다뤄온 주문·결제 도메인과 본질이 같습니다. 정합성·신뢰성·정책 변화에 대한 유연성이 곧 사용자 경험을 좌우합니다.

특히 "도입예정: Claude Code"와 "AI 도구 활용 SDD 경험 우대"는 제가 사내에서 직접 추진해온 일과 정확히 맞닿아 있어, 다우오피스에 AI 에이전트를 안전하게 녹여내는 과정에 즉시 기여할 수 있다고 확신합니다.

## 4. 직무 적합성

① **AI 에이전트 개발 경험** — 사내 AI Tech TF 팀원으로 참여하여 학습한 AI-DLC 전략을 바탕으로, 직속 부서에 LLM → MCP/Tool Gateway → Context API → ReadOnly DB 구조와 CLAUDE.md 라우터화·Skill 기반 로딩 환경을 직접 가이드했습니다. 더 나아가 Jira 티켓 연동 등 실무 워크플로우에 AI를 결합한 사례를 TF에 다시 전파하여 사내 전반의 도입 수준을 끌어올려왔습니다.

② **Java/Spring 운영 경험** — Spring Boot·MSA·RabbitMQ 기반에서 주문 도메인을 전담했습니다. 결제 수단이 늘어날수록 if-else가 누적되던 결제 도메인은 **전략 패턴 기반 OOP 리팩토링**으로 OCP·DIP를 만족하는 확장 가능한 구조로 전환했고, 주문·결제·배송 핵심 시나리오 중심으로 **TestContainer 기반 통합 테스트**를 구축해 정책 변경에도 사이드이펙트 없이 검증 가능한 환경을 만들었습니다. 외부 제휴사 API 호출이 1분 이상 소요되어 주문 스레드를 점유하고 발급 실패가 주문 완료까지 실패시키던 **현금영수증 발급**은 RabbitMQ 기반 비동기 요청-응답 구조로 전환해 장애 격리·재시도·DLQ 기반 안정성을 확보했습니다. **ISMS 대응**에서는 MSA 환경에서 제각각이던 XSS 처리 방식을 정보보안 부서와 협업해 통일된 애노테이션 기반 공통 처리 방식으로 정리·가이드하여 다음 해 점검에서 XSS 지적 건수를 크게 줄였습니다.

③ **자기주도성·공유** — 주어진 일이 아닌 필요한 일을 먼저 찾아 추진하는 편입니다. 외주 협업에서는 주 2회 스크럼·코드 리뷰·도메인 가이드 정리로 팀 생산성을 끌어올렸고, 부서 AI 가이드 수립과 TF 기술 전파 역시 자발적으로 진행해왔습니다.

## 5. 입사 후 포부

두 가지 축으로 기여하겠습니다. ① Claude Code 도입 초기에 부서 가이드 수립 경험을 살려 AI 개발 환경을 빠르게 안착시키고, ② 전자결재·게시판 등 핵심 기능의 정합성·동시성·장애 격리를 강화하겠습니다. "왜 이런 구조여야 하는가"를 함께 논의하며 시스템 전체의 신뢰성을 높이는 동료가 되겠습니다. 감사합니다.
