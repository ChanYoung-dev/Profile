안랩
저는 Java와 Spring Framework 기반으로 웹 서비스를 개발하며, 데이터 정합성과 안정성이 중요한 주문·결제 시스템을 운영해온 백엔드 개발자입니다.

주문/결제 도메인은 금액과 상태 변화가 복잡하게 얽혀 있어 작은 오류도 사용자 경험과 서비스 신뢰도에 직접적인 영향을 미치기 때문에, 항상 정합성과 안정성을 최우선으로 고려하며 개발해왔습니다. 주문서 화면부터 주문 처리 백엔드, 취소·교환·반품 처리까지 전 과정을 직접 구현하며 서비스 흐름 전반을 이해하고 개선해왔습니다. 특히 JSP와 JavaScript를 활용하여 프론트엔드 영역까지 직접 개발하며, 단순히 기능을 구현하는 데 그치지 않고 백엔드와 프론트엔드 간 데이터 흐름과 사용자 인터랙션을 함께 고려하는 풀스택 개발 경험을 쌓았습니다. 이를 통해 API 설계 단계부터 사용자 흐름과 예외 상황을 함께 고려할 수 있었으며, 프론트엔드와 백엔드 간 불필요한 커뮤니케이션 비용을 줄이고 보다 효율적으로 문제를 해결할 수 있었습니다.

주문 시스템은 MSA 구조로 구성되어 있어 서비스 간 데이터 흐름과 정합성을 유지하는 것이 중요했습니다. 저는 오케스트레이션 방식으로 주문 프로세스를 설계하고, 각 서비스의 책임을 명확히 분리하면서도 전체 흐름을 안정적으로 제어할 수 있도록 구성했습니다. 아울러 서비스 간 데이터 정합성을 유지하기 위해 DB를 분리하고, Saga 패턴을 활용하여 분산 트랜잭션 상황에서도 일관성을 유지할 수 있도록 설계했습니다. 이를 통해 복잡한 주문 처리 과정에서도 안정적으로 상태를 관리할 수 있는 구조를 구축했습니다.

기존 주문 시스템에서는 배송비가 특정 상품에 종속된 구조로 설계되어 있어 다양한 정책을 처리하는 데 한계가 있었습니다. 이러한 문제를 해결하기 위해 상품과 배송비 간 관계를 N:N 구조로 재설계했습니다. 이를 통해 다양한 시나리오를 유연하게 처리할 수 있게 되었으며, 기존에 수작업으로 처리되던 업무를 시스템화하여 운영 효율성과 데이터 정합성을 함께 개선할 수 있었습니다.

복잡한 결제 로직을 유지보수하기 쉬운 구조로 개선하기 위해 객체지향적으로 리팩토링을 진행했습니다. 기존의 조건문 중심으로 분기되던 로직을 결제 수단별로 역할을 분리하고, 각 객체가 책임을 가지도록 구조를 재설계했습니다. 이를 통해 새로운 결제 수단이 추가되거나 정책이 변경되더라도 기존 코드를 크게 수정하지 않고 확장할 수 있는 구조를 만들었으며, 코드의 가독성과 유지보수성을 크게 향상시킬 수 있었습니다. 더불어 Oracle 기반 환경에서 SQL 튜닝 경험을 쌓았습니다. 실행 계획을 기반으로 인덱스 활용 여부를 점검하고 쿼리를 개선하여 성능을 최적화했습니다.

테스트 코드 도입을 통해 기능 변경 시 발생할 수 있는 사이드 이펙트를 사전에 검증할 수 있도록 개선했으며, 기존에는 운영 환경에서 직접 확인해야 했던 부분을 사전에 검증할 수 있는 기반을 마련했습니다. 한편 RabbitMQ 기반 비동기 처리 구조를 적용하여 장애 전파를 차단하고, 대규모 트래픽 상황에서도 안정적으로 처리할 수 있는 구조를 설계했습니다. 이를 통해 특정 기능에서 장애가 발생하더라도 전체 서비스에 영향을 주지 않도록 개선하며 시스템의 가용성과 안정성을 높일 수 있었습니다.

보안 측면에서도 운영 경험을 통해 개선을 수행했습니다. 실제 서비스에서 발견된 XSS 취약점을 계기로 입력값 검증과 출력 처리 방식을 전반적으로 점검하고, 공통 처리 로직을 정립하여 시큐어 코딩을 적용했습니다. 그 결과 특정 기능 단위가 아닌 서비스 전체에서 일관된 보안 기준을 유지할 수 있었으며, 보안 역시 시스템 설계의 중요한 요소라는 점을 체감했습니다.

또한 개인 프로젝트로 코인 트레이딩 전략 분석 시스템을 100% AI Agentic Coding으로 개발하며 기술 역량을 확장해왔습니다. 해당 프로젝트에서는 React를 활용해 대시보드 UI를 구현하고, Node.js 기반 멀티프로세스를 통해 전략별 데이터를 병렬 처리하여 성능을 개선했습니다. 이후 AI 서비스를 연동하여 수익률·MDD·승률 등의 지표를 기반으로 전략을 분석하고 비교하는 기능을 구현했습니다. 이 과정에서 AI Agent 기반 개발 방식을 활용하여 빠르게 기능을 구현하고 개선하며, AI를 단순한 도구가 아니라 시스템 기능 확장의 수단으로 활용하는 경험을 쌓았습니다.

이처럼 저는 정합성과 안정성을 기반으로 한 시스템 운영 경험과 함께, 아키텍처 설계, 데이터 모델 개선, DB 성능 최적화, 보안 대응까지 다양한 기술 역량을 실무에 적용해왔습니다. 지금 당장의 기능 구현을 넘어, 장애 상황과 유지보수까지 고려하여 안랩의 시스템을 지속적으로 발전시키는 개발자로 기여하겠습니다.
